24.What is a Pipeline in ADF?

25.What is an Activity?
   it is one individual task inside a pipeline
   i have used 6 activities like
   copy activity 
   lookup activity 
   for each activity  
   if activity  
   script activity 
   executive pipeline activity 
26. explain activities ?
   copy activity -- it is used to move data from source to sink
   lookup activity -- it will read the configuration table and give the information about table to process
   for each activity  -- it will take the records from lookup activity and process step by step
   if activity  -- it will check the table it is full load or increment load
   script activity -- it is used to execute pipeline
   executive pipeline activity -- it will use to call another pipeline once finish current pipeline

connections. I extract the data, apply transformations and data-quality checks, and load it into the target
system. Finally, I schedule and monitor the pipeline
