1,what is serverless sql pool?
  serverless allow us to directly query data from adls using external table without storing the data in the synapse sql pool

2,what is dedicated sql pool?
 we can take data from adls and load it into dedicated sql pool using copy into function
then use sql query for reporting and analytics


3,when to go for serverless sql pool?

   1,unpredictable
   when you have a unpredictable work loads you can use serverless sql pool

   2,Ad-hoc Queries(when we need to access database we can use)
   3, when you need to use serverless with  low cost you can use it but performance also low

4,when to go for dedicated pool?
   1,predictable
   when you have a predictable work loads you can use dedicated pool(daily run pipeline it is fixed it is predictable)

   2, data warehousing(when we want to create complete data warehouse we can use it)
   3, when you need high performance with high cost you can use dedicated pool


5,Adv and Dis-Adv of Severless sql pool? 

   #Advantages of Severless pool
   1, Less Cost
   2, Quick Result

   #Disadvantage of Severless pool
   1,Less workload (it is low performance like using big data)
   2,Not Scalable

6,Adv and Dis-Adv of dedicated sql pool? 

  #Advantage of dedicated pool
  1,high workload (huge big data it is useful)
  2, Scalable (Scalable means compute configure level adjustment)

 #Disadvantage of dedicated pool
 1, High cost
 2, Slower Results(low performance when you write a query in dedicated pool)
